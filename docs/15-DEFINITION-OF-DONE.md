# Definition of Done

## Design
- [ ] Requirement understood
- [ ] Scope and non-goals explicit
- [ ] Domain impact reviewed
- [ ] Trade-offs documented for meaningful choices
- [ ] Design Gate completed when required

## Implementation
- [ ] Business rules in correct layer
- [ ] No business logic hidden in controllers/UI
- [ ] Authorization/resource ownership enforced
- [ ] Transactions and idempotency handled where required
- [ ] Standardized error handling
- [ ] Adequate observability

## Verification
- [ ] Domain tests
- [ ] Application tests
- [ ] API/integration tests where applicable
- [ ] Critical happy path verified
- [ ] Failure paths verified
- [ ] Regression tests for discovered bugs

## Data / Operations
- [ ] Migration reviewed
- [ ] Test/seed data impact reviewed
- [ ] Logging/audit impact reviewed
- [ ] Deployment/configuration impact reviewed

## Documentation
- [ ] Relevant docs updated
- [ ] Decision log updated when decisions change
- [ ] Open questions updated
- [ ] Acceptance evidence recorded

## Final
- [ ] No blocker hidden by workaround
- [ ] Root cause addressed for known defects
- [ ] Repository remains clean and understandable
